# PeakPerformers


## Proyecto: ControlStock
**Sistema web de gestión y control de inventarios**

### Descripción del proyecto

**ControlStock** es un proyecto académico desarrollado por el equipo **PeakPerformers**, enfocado en la creación de una aplicación web para la gestión y el control de inventarios en pequeñas y medianas empresas, especialmente ferreterías.

El sistema busca ofrecer una herramienta práctica, organizada y fácil de utilizar que permita administrar productos, clasificarlos por categorías, controlar las existencias disponibles y registrar los movimientos de entrada y salida de mercancía.

Además, contempla funcionalidades para la gestión de proveedores, el registro de ventas, las órdenes de compra y la administración de usuarios mediante roles y permisos.

### Objetivo general

Desarrollar una aplicación web que facilite la administración de inventarios de una ferretería, mejorando el control de productos, el seguimiento de las existencias y la organización de la información comercial.

### Tecnologías utilizadas

El proyecto se desarrolla utilizando las siguientes tecnologías:

- **Frontend:** React, JavaScript, Vite y CSS.
- **Backend:** Node.js y Express.
- **Base de datos:** MariaDB.
- **Comunicación:** API REST.
- **Control de versiones:** Git y GitHub.

### Arquitectura del sistema

ControlStock utiliza una **arquitectura modular monolítica**, que permite organizar el backend en módulos y separar las responsabilidades mediante rutas, controladores y servicios.

La aplicación web se comunica con el backend mediante una API REST, mientras que MariaDB se encarga del almacenamiento y la administración de los datos.

### Estado del desarrollo

El proyecto se encuentra en fase de desarrollo. Actualmente se ha configurado la estructura inicial del backend, establecido la conexión con MariaDB y desarrollado el módulo básico de categorías, con operaciones para consultar y registrar información.

Las demás funcionalidades se implementarán progresivamente, siguiendo una metodología de trabajo colaborativo mediante ramas independientes en GitHub.

### Equipo de desarrollo

**PeakPerformers**

Proyecto académico desarrollado de manera colaborativa, con responsabilidades distribuidas entre los integrantes del equipo para el desarrollo del frontend, backend y las pruebas del sistema.
